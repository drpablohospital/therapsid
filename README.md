# 🦊 Therapsid v2.1.2

Red federada descentralizada para datos criticos Latinoamerica.

## Instalacion

```bash
sudo dpkg -i therapsid-v2.1.2.deb
therapsid start
```

## Acceso

- Dashboard: http://localhost:8767/dashboard
- Login: demo@therapsid.org / ***
- Admin: http://100.127.123.55:5002

## Features v2.1.2

- Dashboard futurista rosa/verde
- Login visual con formulario
- Auth distribuida (JWT + SQLite local)
- Demo user automatico
- Conexion a Sinapsid admin
- Tema claro/oscuro toggle

## Comandos

```bash
therapsid start    # Iniciar
therapsid stop     # Detener
therapsid status   # Ver estado
```
